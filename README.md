# LINE Preview

หน้าส่งต่อลิงก์ (redirect) ของงานเมสเซนเจอร์ — เปิดแล้วพาไปหน้าปลายทางทันที

- รูปแบบ: `https://itsupport2-pixel.github.io/line-preview/?title=...&desc=...&img=...&to=<ลิงก์ปลายทาง>`

`title` `desc` `img` = หัวข้อ/คำอธิบาย/รูป · `to` = ลิงก์ที่จะเปิดต่อ (ใส่แบบ encode) · หัวข้อการ์ดตอนแชร์ใน LINE จะเป็นค่าเริ่มต้นในไฟล์ ("Messenger — New Job") เพราะ LINE ไม่รัน JavaScript
